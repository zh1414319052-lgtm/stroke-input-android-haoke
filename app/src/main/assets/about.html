Haoke optimized edition and upstream attribution

This is the Haoke optimized edition 1.7.0-haoke.13, based on Conway’s Stroke Input Method v1.7.0. The original copyright and GPL-3.0-only license are retained. Haoke changes cover themed settings/keyboards, font and control adaptation, offline handwriting/speech, and signed version checks. Source for this optimized edition is public. Download from Haoke.

The interface uses static Noto Sans SC weights 400/700 under SIL OFL 1.1. Bundled models, runtimes and the original keyboard font retain their separate licenses.

The current Haoke version appears under “Check for Haoke updates” in settings. Input, handwriting and speech recognition remain on this device. Only signed version checks connect to the Haoke website, from the foreground settings screen. No input or audio is sent. Updates are never installed automatically. See the bundled privacy policy.
