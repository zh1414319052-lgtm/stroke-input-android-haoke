Offline voice recognition in the Haoke build of Stroke Input Method
Recorded: 2026-10-29

This directory contains the SenseVoice-Small-Yue int8 model, not the unchanged
SenseVoice-Small base checkpoint. The Cantonese fine-tuning is from
ASLP-lab / WenetSpeech-Yue, converted to ONNX and quantized by the sherpa-onnx
project. Model and token files have not been modified after extracting the
2025-09-09 distribution.

Runtime behaviour:
  Recognition runs locally; no network service or API key is used.
  The app requests microphone permission on first use. Recorded audio is kept
  only in memory for recognition and is neither saved nor uploaded.
