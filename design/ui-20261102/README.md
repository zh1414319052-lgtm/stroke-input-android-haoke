# 笔画输入法 · 可编辑设计基准

`stroke-ui.haoke-ui.json` 是本轮结构化设计源，包含设置长页、首次启用、三主题、键盘和布局选择器的状态。
画板采用 360dp 逻辑宽度。颜色映射 `themes.xml`、`KeyboardTheme.java`，尺寸映射 `dimens.xml`。
外边距20dp，设置卡片圆角18dp、按钮圆角12dp/触控高48dp、字段最小高58dp。
界面字体为 Noto Sans SC 静态400/700字重（SIL OFL 1.1），真实字体及许可在 app 资源中。
图标与输入、手写、语音、设置保存和升级身份保留原有语义。PNG概念图仅作参考，应用由原生控件和矢量实现。
